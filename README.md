# เงาไม้ การ์เด้น

เว็บตัวอย่างของบริษัทสมมุติ ใช้ Node.js 24 กับ SQLite

```bash
npm install
npm run admin
npm run seed
npm start
```

- เว็บ: http://127.0.0.1:8090
- แอดมิน: http://127.0.0.1:8090/admin
- `npm run admin` สร้างหรือรีเซ็ตรหัสผ่านจาก `ADMIN_EMAIL` และ `ADMIN_PASSWORD` ใน `.env`
- `npm test` รันชุดทดสอบ
- ถ้าเพิ่มหรือเปลี่ยนตำแหน่งรูปในหน้าเว็บ ต้องแก้ทั้ง `src/site.mjs` และ `seed/seed.mjs`

ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/`: ฐานข้อมูล `site.db`, รูป `uploads/` และสำรองรายวัน `backups/`

ขึ้นเว็บจริง: ตั้ง `SITE_URL` เป็น `https://...`, ใช้ reverse proxy ที่เปิด HTTPS, เก็บ `data/` บนดิสก์ถาวร และตั้ง `SITE_INDEXABLE=1` เฉพาะเมื่อเป็นบริษัทจริง
การล็อกล็อกอินนับตาม IP ผู้ใช้: บน Render (ตัวแปร `RENDER` ถูกตั้งให้อัตโนมัติ) อ่านจากค่าสุดท้ายของ `X-Forwarded-For` ที่อื่นใช้ IP ของการเชื่อมต่อ ถ้าย้ายไปหลัง proxy อื่นให้แก้ `clientIp()` ใน `src/auth.mjs`

## ตัวเลขรูปภาพ: ตั้งตาม host ฟรี ปรับได้

ตัวเลขเหล่านี้ใน `src/images.mjs` ตั้งให้พอดีกับ host ฟรีที่ใช้อยู่ (Render แพ็กเกจ free, RAM 512 MB) ไม่ใช่ข้อจำกัดของเว็บ ถ้าย้ายไป host ที่ใหญ่กว่าหรือต้องการเว็บคมบนจอ 2K/4K ให้ปรับได้:

| ค่า | ตอนนี้ | ทำหน้าที่ | ควรรู้ก่อนปรับ |
|---|---|---|---|
| `MAX_PIXELS` | 50 ล้านพิกเซล | ปฏิเสธรูปที่ใหญ่เกินตอนอัปโหลด เพราะ sharp แตกรูปเต็มขนาดในหน่วยความจำ (รูปใหญ่มากเคยกิน RAM ประมาณ 310 MB) | รูป 4K มีแค่ ~8 ล้านพิกเซล รูป 8K ~33 ล้านพิกเซล จึงไม่ถูกจำกัด เพิ่มค่านี้ต่อเมื่อ RAM มากขึ้น |
| `WIDTHS` | 480, 960, 1600, 2000 px (WebP quality 90) | ขนาดรูป WebP ที่สร้างและใส่ใน `srcset` | ถ้าเพิ่มขนาดใหม่ รูปที่อัปโหลดไว้แล้วจะไม่มีไฟล์ขนาดนั้นและโหลดไม่ขึ้น ต้องสร้างเพิ่ม ดิสก์ใน `data/uploads` จะโตขึ้นด้วย |
| `MAX_IMAGE_BYTES` | 8 MB | ขนาดไฟล์สูงสุดต่อรูป | ข้อความ "8 MB" ในหน้าแอดมินและข้อความ error เขียนไว้ตรง ๆ ต้องแก้ตามด้วย |

หลังเพิ่มขนาด 2000px ต้องรัน `npm run sizes` หนึ่งครั้งกับข้อมูลเดิมที่เก็บถาวรไว้ (เช่นเครื่องตัวเองหรือ host ที่มีดิสก์ถาวร) เพื่อสร้าง `-2000.webp` ของรูปที่อัปโหลดไว้แล้วจาก `-1600.webp` สคริปต์สร้างเฉพาะไฟล์ที่ยังไม่มี ไม่ลบหรือเขียนทับ รันซ้ำได้ (รูปเดิมไม่มีพิกเซลเกิน 1600px ไฟล์ใหม่จึงช่วยแค่ไม่ให้ 404 ไม่ได้คมขึ้น) บน Render แพ็กเกจ free ไม่ต้องรัน เพราะ `data/` ถูกสร้างใหม่ทุกครั้งที่เริ่มเซิร์ฟเวอร์ (`npm run seed`) และรูปทุกรูปจะได้ขนาด 2000px เอง

ไอคอนแบรนด์ใน `src/icons` มาจาก simple-icons (CC0) ไอคอนหน้าแอดมินจาก Phosphor Icons (ไฟล์ขึ้นต้น `ph-`, สัญญาอนุญาต MIT) และไอคอนโทรศัพท์/อีเมลหน้าเว็บจาก lucide (ไฟล์ขึ้นต้น `lu-`, สัญญาอนุญาต ISC)
